# ME F216 — Torsion Test Analysis

Browser-based torsion-test calculator for the ME F216 Materials Testing Laboratory.

## Student use
Open the GitHub Pages URL. No Google/Colab account and no software installation are required.

Students can:
- enter angle and torque readings in a table;
- choose kgf·cm or kgf·m;
- change the number of initial points used for the elastic-region regression;
- calculate slope, R², and G;
- view the elastic-region and complete torque–twist plots;
- download PNG graphs and processed CSV data.

## GitHub Pages
1. Create a **public** GitHub repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. GitHub will publish the site at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

GitHub Pages publishes static files such as `index.html` directly from a repository.
